# STA4028Z Portfolio Theory — Assignment 1

MV backtesting and out-of-sample performance analysis: tangency portfolio
construction, in-sample vs out-of-sample Sharpe ratios, and rolling-window
backtesting.

## Requirements

- MATLAB R2021b or later
- Optimization Toolbox
- Financial Toolbox

## Quick start

1. Open the relevant script in [scripts/](scripts/) in VS Code (with the
   MathWorks MATLAB extension installed) or in MATLAB directly.
2. Set the current folder to the repo root.
3. Run the script.

## Folder structure

- [data/raw/](data/raw/) — original, unmodified source data
- [data/derived/](data/derived/) — generated/processed data
- [functions/](functions/) — reusable MATLAB (.m) function files
- [scripts/](scripts/) — main assignment scripts
- [docs/](docs/) — derivations and supporting material
- [exports/](exports/) — executed PDF/output exports
